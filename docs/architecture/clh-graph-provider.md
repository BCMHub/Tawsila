# Graph provider integration

Graph First, Files Second. Graph results guide selection; current source/runtime evidence remains authoritative.

The optional reference adapter is pinned to locally installed graphifyy 0.8.31. A real Python fixture verified local `update <staged-code> --no-cluster` extraction in credential-free staging. No hooks, global graph merges, network extraction or instruction installation occur. Missing/incompatible providers return UNAVAILABLE and use targeted source fallback.

The legacy nodes/links output lacks reliable end ranges; normalized ranges remain null and retrieval uses verified source windows. Coverage is explicitly incomplete, inferred relationships remain labeled, and related tests are candidates. Only Python fixture behavior is capability-verified; mobile-language/dynamic/generated-code coverage needs project fixtures.

The graph service supports incremental file-delta refresh routing, immutable worktree snapshots and bounded full rebuilds. Graphify advertises no verified incremental mode, so it uses full refresh/fallback. Never assume main graph freshness or guaranteed token savings.
